About Translator

Mission Statement:

This advanced translation platform is dedicated to the preservation and revitalization of the Runyankore language. By leveraging modern artificial intelligence, we bridge cultural heritage with cutting-edge technology to make language learning and translation accessible to all.

Core Features:

  • Smart Bidirectional Translation
  • Expansive Curated Dictionary (with future community contribution)
  • Translation History & Learning Tools
  • Progressive Web App (PWA) with offline capabilities for Mobile & Desktop

For developer information, please visit the About Developer page.

Basic Translation Guide

1
Bi-directional Translation

Translate between Runyankore and English in both directions:

  • Runyankore → English: Type in the left box and click "Translate to English"
  • English → Runyankore: Type in the right box and click "Translate to Runyankore"
2
Quick Phrases

Use the pre-loaded quick phrases to get started quickly. Click any phrase button to automatically insert it into the translation box.

Dictionary Search Features

1
Intelligent Search

Use the dictionary search box to look up words and phrases:

  • Autocomplete: Start typing and get instant suggestions
  • Smart Matching: Search works with partial words and phrases
  • Both Languages: Search in Runyankore or English

Offline & Online Usage

Offline Mode

  • After first load, works without internet

Troubleshooting & Updates

Important Update Instructions

If the app fails to update automatically, follow these steps:

  1. Visit your web browser settings
  2. Delete all browser history and cache related to this app
  3. Clear cookies and site data for this domain
  4. Close all browser tabs/windows of the app
  5. Reopen the app in your browser
  6. Allow 10-20 seconds for automatic updates to load

This forces the browser to download fresh files and ensures you get the latest version.

Common Issues
Problem: App shows old version
Solution: Follow the update instructions above
Problem: Offline dictionary not loading
Solution: Connect to internet → Click "Refresh" button
Problem: Translation not found
Solution: Try different phrasing or use online mode for Smart translation

Install as App (PWA)

Chrome/Edge/Android

Click the "Install App" button (floating button) or use browser menu → "Install App"

Safari (iPhone/iPad)

Tap Share button → Scroll down → "Add to Home Screen"

PWA Benefits:
  • App icon on home screen
  • Works offline like native app
  • Faster loading
  • Better sleep management (prevents screen lock)
  • No app store downloads required
